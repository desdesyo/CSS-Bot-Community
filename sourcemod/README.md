# CSSBC SourceMod bridge

Это **реально устанавливаемый серверный слой** для CS:S. Он не требует компиляции C++ ядра и работает как SourceMod-плагин.

## Установка
1. Установить SourceMod и SDKHooks для CS:S.
2. Скопировать `sourcemod/scripting/cssbc.sp` в `addons/sourcemod/scripting/`.
3. Скомпилировать через компилятор SourceMod (`spcomp cssbc.sp`).
4. Поместить `cssbc.smx` в `addons/sourcemod/plugins/`, перезапустить карту.
5. Настройки появятся в `cfg/sourcemod/cssbc.cfg`.

## Команды
- `sm_cssbc` — статус.
- `sm_support 1` — поддержка за $1000.
- `sm_support 2` — поддержка за $3000.
- `sm_support 3` — отряд за $9000 (пока объявление заказа, без NPC-spawn).
- `sm_juggernaut` — $16000 и минимум 3 погибших союзника; 500 HP (настраивается).

## Честный статус
Bridge подключает команды, экономику, события раунда, русский чат и базовый режим Джаггернаута к живому серверу. Он **не спавнит NPC поддержки**, не реализует шесть отдельных бронепластин, Source HUD/VGUI и новую бот-навигацию. Для них нужен полноценный CS:S SDK/Metamod game plugin и серверные entity-интерфейсы. Portable C++ core остаётся отдельным модулем.
