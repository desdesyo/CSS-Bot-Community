# CSS Bot Community — SourceMod bridge

Это ранний устанавливаемый серверный прототип для Counter-Strike: Source. Он **не является готовой DLL-модификацией** и пока не заменяет штатный AI ботов.

## Что реально работает в bridge 0.1.1

- Команда `sm_cssbc` показывает статус плагина.
- Команда `sm_juggernaut` покупает Джаггернаута за $16 000, если у игрока есть минимум три погибших союзника в его команде.
- Здоровье Джаггернаута задаётся через `cssbc_juggernaut_hp` (по умолчанию 500).
- Число погибших союзников вычисляется непосредственно в момент покупки: повторный подсчёт смертей больше не завышает условие.
- `sm_support` пока сообщает о недоступности NPC-отряда и **не списывает деньги**.

## Установка

1. На сервере CS:S должен быть установлен совместимый с его сборкой MetaMod:Source и SourceMod.
2. Скопируй `sourcemod/scripting/cssbc.sp` в `addons/sourcemod/scripting/`.
3. Открой CMD в этой папке и выполни:

   ```bat
   spcomp.exe cssbc.sp -o ..\plugins\cssbc.smx
   ```

4. Убедись, что файл `addons/sourcemod/plugins/cssbc.smx` появился.
5. Перезапусти карту или сервер.
6. Проверь в консоли сервера: `sm plugins list`.
7. В игре проверь `!cssbc` или `sm_cssbc`.

После первого запуска SourceMod создаст `cfg/sourcemod/cssbc.cfg`. Основные настройки:

- `cssbc_enabled 1` — включить мод.
- `cssbc_support_enabled 1` — включить ответ команды поддержки (сам NPC-отряд пока не реализован).
- `cssbc_juggernaut_hp 500` — здоровье Джаггернаута.

## Ограничения и следующий этап

Плагин пока не создаёт NPC поддержки, не реализует шесть отдельных бронепластин, новый HUD/VGUI, новую навигацию и замену штатного AI. Для этих функций требуется отдельная интеграция с игровыми интерфейсами CS:S. Совместимость SourceMod с конкретной сборкой v34 должна быть проверена на самом сервере; успешная компиляция .sp сама по себе не доказывает совместимость рантайма.
