# CSS Bot Match Log Collector

Набор для сбора логов длительных матчей CS:S с ботами (например, 6 CT vs 6 T), чтобы затем передавать архив на GitHub для анализа.

## Быстрый сбор через консоль CS:S

1. Включите консоль разработчика.
2. Перед матчем выполните команды (укажите уникальное имя):
   ```
   con_timestamp 1
   con_logfile "cssbc_match_YYYYMMDD_HHMMSS.log"
   ```
3. Запустите матч 6 на 6 и оставьте ботов играть.
4. После матча остановите запись:
   ```
   con_logfile ""
   ```
5. Найдите файл в каталоге игры (обычно `cstrike/`, точный путь зависит от сборки) и положите в папку `logs/` репозитория.

Для настройки ботов можно попробовать `bot_quota 12`, `bot_quota_mode fill`, `mp_limitteams 0`, `mp_autoteambalance 0`. Проверьте фактический состав 6/6 в игре: эти команды не во всех конфигурациях гарантируют ровно шесть игроков на сторону.

## Что приложить к матчу
- Полный console log, без вырезанных фрагментов.
- Карта, режим, состав CT/T, длительность и число раундов.
- Версия игры, модификации и параметры запуска.
- Отдельно описать зависания, ошибки или странное поведение ботов.

## Структура
```
logs/
  YYYY-MM-DD_map_short-description/
    console.log
    match-info.md
```
Шаблон описания: `MATCH_INFO_TEMPLATE.md`.

## Перед публикацией
- Убедитесь, что лог содержит начало и конец матча.
- Не редактируйте оригинал лога; комментарии пишите в `match-info.md`.
- Не добавляйте Steam-логи с личными данными, секреты, дампы памяти или конфиги с паролями.
