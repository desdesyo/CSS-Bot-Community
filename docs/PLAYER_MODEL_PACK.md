# CSSBC Player & Support Model Pack

## Included original characters

| Model | Faction / role | Visual identity |
|---|---|---|
| `t_raider` | Terrorist | Tan field clothing, olive webbing, head wrap |
| `t_insurgent` | Terrorist | Dark clothing, tan rig, face covering |
| `ct_assault` | Counter-terrorist | Navy tactical uniform, black plate carrier, helmet |
| `ct_recon` | Counter-terrorist | Olive recon uniform, compact black rig, helmet |
| `support_medic` | Support | Olive uniform, red medical identifiers, helmet |
| `support_sniper` | Support | Grey low-profile clothing, dark equipment, hood |
| `support_heavy` | Support | Reinforced dark uniform, steel-toned heavy armour |

These are original CSSBC geometry sources, not extracted Valve models. The pack is deliberately low-poly and uses a shared humanoid skeleton to keep memory and draw cost modest.

## Generate source assets

Run with Python 3:

```sh
python tools/model_pack/generate_pack.py
```

Output: `tools/model_pack/generated/<model>/model.smd`, `idle.smd`, and a matching QC file, plus VMT material templates.

## Compile for Counter-Strike: Source

The generated SMD/QC sources are not runtime models yet. Compile each QC with a compatible Source `studiomdl` toolchain matching the target game branch. The output must include MDL, VVD and the appropriate VTX variant. Copy compiled outputs and authored VTF textures into the local CS:S installation only after validation.

## Required validation before enabling in-game

- Replace the generated VMT base-texture placeholders with authored texture maps and compile VTFs.
- Check skeleton orientation, proportions, hitboxes and attachment points in HLMV.
- Add/retarget the CS:S player animation set (idle, walk, run, crouch, jump, reload/weapon poses, death) before replacing live player models.
- Verify team assignment, player model paths, support NPC model paths, collision and LOD/performance on the actual v34 build.
- Keep first-person arms and weapon viewmodels separate; this pack covers third-person character bodies only.
