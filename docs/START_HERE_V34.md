# CSS Bot Community — начать здесь (CS:S v34)

Это рабочая инструкция для текущей ветки `sdk-foundation`. Проект собирается под **Windows / Win32 (x86)**. Python и SourceMod для целевой GameDLL-сборки не используются.

## Что уже подключено в проекте

- Зафиксирован исходник CS:S v34: `sl1mshady-cs/cssv34-client`, commit `55f860bf42a537ac55aaef684f6fa0effee714a8`.
- В GitHub Actions настроена сборка исходников GameDLL под MSVC x86.
- Скрипт `tools/integrate-v34-gamedll.ps1` переносит CSSBC Brain/Economy/Tactics в дерево игры и добавляет вызов CSSBC из `CCSBot::Update`.
- Игровой адаптер получает состояние существующего бота и может выдать решения отступить или искать укрытие.
- Это **не готовая замена всей игры и не новый NPC-спавнер**. Первый проверяемый результат — сборка GameDLL с подключённой тактической логикой существующих CS:S-ботов.

## Что сделать сейчас — только GitHub

1. Открой ветку проекта: https://github.com/desdesyo/CSS-Bot-Community/tree/sdk-foundation
2. Открой вкладку **Actions**: https://github.com/desdesyo/CSS-Bot-Community/actions
3. Выбери workflow **Build CSSBC native modules (Win32)**.
4. Открой самый новый запуск для ветки `sdk-foundation`.
5. Дождись завершения задания **build-v34-gamedll**.
6. Если оно завершилось успешно, открой этот запуск → **Artifacts** → скачай **CSSBC-v34-GameDLL-Win32**.

Не скачивай артефакт `CSSBC-VSP-Win32` для установки GameDLL: это отдельный необязательный серверный плагин-загрузчик. Для нашего первого игрового теста нужен именно `CSSBC-v34-GameDLL-Win32`.

## Если сборка красная

1. Открой упавшее задание `build-v34-gamedll`.
2. Раскрой первый шаг с красным крестом.
3. Скопируй сюда текст ошибки и название шага.

Не нужно угадывать причину, запускать Python или вручную компилировать SDK. Сборка выполняется на GitHub runner с Visual Studio 2022 x86.

## Важно перед установкой

**Пока не заменяй никакие DLL в папке игры.** Сначала нужно получить успешный артефакт, проверить его состав и подтвердить точный путь GameDLL в твоей сборке CS:S v34. Перед будущей заменой оригинальный файл будет сохранён как резервная копия. Непроверенную DLL нельзя ставить поверх рабочего сервера.

## Что означает успешная сборка

Успешный workflow подтверждает только то, что интегрированный серверный GameDLL скомпилировался. Он ещё не подтверждает запуск на твоей конкретной сборке, работу ботов в матче или отсутствие крашей. Это проверяется следующим отдельным игровым тестом.

## Цель первого игрового теста

- сервер загружается с CSSBC GameDLL;
- стандартные CS:S-боты создаются и играют как раньше;
- при подходящей ситуации CSSBC может переключить бота на отступление или поиск укрытия;
- смена карты и завершение раунда не вызывают краш.

После этого можно подключать следующие игровые события, экономику, бронепластины и систему поддержки.
