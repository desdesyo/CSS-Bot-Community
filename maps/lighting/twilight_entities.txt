## Notes
- VMF uses entity blocks with key/value pairs; this file is a readable keyvalue template, not standalone valid VMF.
- The exact key names and HDR behavior depend on the Source branch/compiler; verify in Hammer and compile one test map first.
- Keep brightness conservative: test player visibility and long sightlines after every lighting change.
- A dusk skybox is a separate material asset. Without one, global light color alone won't create a sunset horizon.
