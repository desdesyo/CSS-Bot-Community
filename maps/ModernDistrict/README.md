# CSSBC Modern District (CS:S v34)

Map concept: 60% Dust2-inspired sandstone district + 40% modern city. This directory is the map workspace.

## Planned playable layout
- West: old sandstone district / Dust2-inspired lanes and courtyards.
- Center: wide connector boulevard, cross-street and covered passage.
- East: modern glass/concrete office blocks, lobby interiors and roof access.
- Street cover: parked cars, dumpsters, concrete barriers and crates.
- Spawn sets: T west/southwest deployment pockets; CT east/northeast pockets.
- Round deployment: CSSBC chooses a random valid spawn from the team's set; avoid choosing a point occupied by a player and enforce a minimum separation.

## Build target
The deliverable is a Hammer VMF compiled with the CS:S v34 VBSP/VVIS/VRAD toolchain. A VMF is source geometry; it is not itself a playable BSP.

**Status:** layout/specification only. No VMF/BSP has been generated or tested yet.
