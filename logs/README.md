# Match logs

Сюда добавляются архивы матчей. Каждый матч — отдельная папка с `console.log` и заполненным `match-info.md` (см. `tools/log-collector/MATCH_INFO_TEMPLATE.md`).

**Не коммитьте** логи Steam/системы с личными данными, токены, пароли, дампы памяти или конфиги с секретами. Большие логи лучше прикладывать ZIP-архивом GitHub Release/Issue, если они превышают лимит Git.
